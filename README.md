Launch Radar: early finds first, checked twice out-of-sample, every farm plan costed. A token launch radar that flags 11 early finds from the snapshot's own rules — small, young, growing or broad — then prices all 198 pre-token protocols by value-if-it-launches times launch odds, with the ablation table, the odds calibration and the band honesty check on screen 1, and your farm priced live on every row.

## Run it

```sh
node main.ts --input input --output output
```
